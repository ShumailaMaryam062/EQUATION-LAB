About EquationLab

A Python package for solving differential equations using artificial neural networks based on PyTorch.

Key Features:

ODE Solver - First-order and higher-order ODEs

PDE Solver - Cartesian & spherical coordinates

Continuous Solutions - Differentiable everywhere

PyTorch Backend - GPU acceleration support

Quick Reference

Common ODEs:

  • dx/dt = -x - Exponential decay
  • dx/dt = x - Exponential growth
  • d²x/dt² = -x - Harmonic oscillator

Parameters:

  • Equation: The differential equation to solve
  • Initial Condition: Value at t=0
  • Time Range: Integration interval
